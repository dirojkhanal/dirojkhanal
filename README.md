## About Me

I'm a software developer from Kathmandu, Nepal, interested in building practical, scalable web applications and understanding how systems work under the hood.

- Building **Gurkha Works**, an office management and team operations platform.
- Developing a **Second Brain** application for personal knowledge management.
- Working with React, Next.js, Node.js, REST APIs, and relational databases.
- Exploring LLM integration, retrieval-augmented generation (RAG), and AI-powered product features.
- Focused on clean code, problem-solving, and continuous improvement.
